# Perfil Global de la Organizacion

Este es un repositorio especial utilizado para centralizar la configuracion, plantillas y documentacion comun de todos nuestros proyectos en GitHub. El contenido de este archivo se muestra como la pagina de inicio publica de nuestra organizacion.

## Proposito del Repositorio .github

Este espacio almacena recursos globales que ayudan a mantener la consistencia en el desarrollo y la colaboracion comunitaria:

* Archivos de Comunidad: Guias de contribucion, codigos de conducta y politicas de soporte aplicables a todos los repositorios derivados.
* Plantillas Automatizadas: Formatos estandarizados para reportes de errores (Issue Templates) y solicitudes de integracion de codigo (Pull Request Templates).

---

## Otros Repositorios Especiales en GitHub

Ademas del repositorio `.github`, la plataforma cuenta con otras dos estructuras que cumplen funciones especificas:

### Repositorio de Perfil Personal (nombre-de-usuario)
* Funcion: Permite crear una presentacion personalizada con texto, imagenes o estadisticas que aparece en la parte superior del perfil publico del usuario.
* Configuracion: El nombre del repositorio debe coincidir exactamente con el nombre de usuario de la cuenta y configurarse como publico.

### Repositorio de GitHub Pages (nombre-de-usuario.github.io)
* Funcion: Actua como un servidor de alojamiento gratuito para publicar sitios web estaticos directamente desde los archivos del repositorio.
* Configuracion: Debe llamarse obligatoriamente con la extension `.github.io` al final del nombre del usuario u organizacion.
